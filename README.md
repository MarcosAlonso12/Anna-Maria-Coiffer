# Anna-Maria-Coiffer
🌸 Loja de Perfumes - Este repositório contém o desenvolvimento de uma loja virtual de perfumes e produtos, com foco em uma experiência elegante, intuitiva e funcional. O projeto contempla catálogo de produtos, carrinho de compras, finalização de pedidos e emissão de notas fiscais para os clientes.

O sistema prevê acesso para clientes e administradores, com funcionalidades específicas para cada perfil:

Cliente: cadastro, acesso à conta, histórico de compras e consulta às notas fiscais.
Administrador: gerenciamento de usuários, cadastro e atualização de produtos, controle de vendas e acompanhamento de pedidos.
Relatórios: histórico de vendas e relatórios por período para acompanhar o desempenho da loja.
