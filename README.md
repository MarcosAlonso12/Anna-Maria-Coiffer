# Anna-Maria-Coiffer
🌸 Loja de Perfumes - E-commerce Este repositório contém o desenvolvimento de uma loja virtual de perfumes, com foco em oferecer uma experiência elegante, intuitiva e funcional para os usuários. O sistema permite que clientes naveguem por fragrâncias, visualizem detalhes dos produtos, adicionem itens ao carrinho e finalizem suas compras.
